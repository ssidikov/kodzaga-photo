# Guide rapide du tableau de bord admin

## Acces

Ouvrir `/admin`, puis se connecter avec le compte administrateur.

Le menu lateral donne acces a :

- **Vue d'ensemble** : statistiques rapides et dernieres reservations.
- **Reservations** : liste complete des demandes clients.
- **Tarifs** : modification des packs et options affiches sur le site.

## Gerer les reservations

Dans **Reservations**, utiliser la recherche ou le filtre de statut pour retrouver une demande.

Cliquer sur une reservation pour voir les details :

- informations client,
- prestation choisie,
- date et lieu souhaites,
- options,
- message,
- notes internes.

Mettre a jour le statut selon l'avancement :

- Nouveau,
- Contacte,
- Confirme,
- Termine,
- Annule.

## Gerer les tarifs

Dans **Tarifs**, modifier :

- les groupes de packs,
- le nom du pack,
- le prix,
- les elements inclus,
- les notes,
- le badge,
- la mise en avant,
- la visibilite sur le site,
- les options a la carte.

Cliquer sur **Sauver** apres chaque modification.

Une notification confirme que le changement est enregistre.

## Voir le resultat

Depuis la page **Tarifs**, cliquer sur **Voir le site** pour ouvrir la section publique des tarifs.

Les packs actifs apparaissent sur la page d'accueil et dans le formulaire de reservation.
