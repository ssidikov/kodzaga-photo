# Contributing

Thanks for improving this RGPD agent skill.

## Guidelines

- Keep `SKILL.md` concise and action-oriented.
- Put long checklists, examples, and templates in `references/`.
- Do not add instructions that present the skill as legal advice.
- Prefer official and current EU/Spanish privacy sources for legal statements.
- Use synthetic examples; do not include real personal data.

## Local validation

```bash
npx skills add . --list
```

Then preview the skill files and confirm `SKILL.md` points only to local references.
