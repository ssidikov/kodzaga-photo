# Security Policy

This repository contains agent instructions and supporting Markdown files.

## Reporting issues

If you find prompt-injection risks, hidden instructions, malicious content, or privacy/security concerns, open a GitHub security advisory or private issue with:

- Affected file and section
- Expected risk
- Suggested remediation

## Privacy note

Do not submit real personal data, customer records, secrets, credentials, or confidential legal material in issues or pull requests. Use synthetic examples instead.
